# Googleフォーム設定手順

問い合わせページでは、無料デモへの導線と、Googleフォームを使った導入相談を併用します。商品・料金の選択肢はLP、FAQ、利用条件と必ず同じ内容に保ちます。

## 1．フォームを作成・更新する

1. `https://forms.google.com/` を開きます。
2. 対象フォームを編集します。
3. フォーム名は `クチコミスターズ｜無料デモ・導入相談` とします。
4. 説明文は次を基準にします。

> QR／URL、選択式アンケート、AI文章生成によるGoogleクチコミ獲得支援についてご相談いただけます。初回は55,000円（税込）・30日間、Googleクチコミ10件到達保証です。送信前にプライバシーポリシー（https://kuchikomi-stars.com/privacy/）をご確認ください。

## 2．質問項目を設定する

次の順番を推奨します。

| 項目 | 質問形式 | 必須 |
|---|---|---:|
| 会社名・店舗名 | 記述式 | はい |
| ご担当者名 | 記述式 | はい |
| メールアドレス | 記述式（メール形式の回答検証） | はい |
| GoogleマップURL | 記述式 | はい |
| WebサイトURL | 記述式 | いいえ |
| 店舗数 | 記述式 | いいえ |
| ご希望の内容 | ラジオボタン | はい |
| 現在お困りのこと | チェックボックス | はい |
| ご相談内容・補足 | 段落 | いいえ |
| プライバシーポリシーへの同意 | チェックボックス | はい |

「ご希望の内容」の選択肢：

- 無料デモについて
- 初回55,000円・Googleクチコミ10件到達保証について
- クチコミ集客プラン（月額33,000円）
- クチコミ集客プラン年間一括（330,000円／12か月）
- MEO・AIO運用プラン（月額66,000円～）
- 複数店舗・個別カスタマイズ
- その他

「現在お困りのこと」の選択肢：

- お客様にクチコミを依頼しても投稿まで進まない
- 何を書けばいいか分からず、お客様の投稿負担が大きい
- 新しいクチコミが増えない
- クチコミ返信やGoogleビジネスプロフィール運用が止まっている
- MEO順位や競合状況を継続して確認できていない
- AI検索で自社がどう見えているか分からない
- 何から改善すべきか分からない
- その他

同意項目は `プライバシーポリシーを確認し、個人情報の取扱いに同意する` とし、必須にします。

## 3．フォーム設定を確認する

Googleアカウントへのログインを必須にしない設定にします。

- 組織内のユーザーに限定：オフ
- 回答を1回に制限：オフ
- 回答の編集を許可：オフ
- 質問の順序をシャッフル：オフ
- テストにする：オフ
- メールアドレス収集：フォーム内の必須項目で入力してもらう

送信後の確認メッセージ：

> お問い合わせありがとうございます。内容を確認後、担当者からご連絡します。

「回答」タブのメニューから「新しい回答についてのメール通知を受け取る」をオンにします。必要に応じて回答先をGoogleスプレッドシートへ接続します。

## 4．公開前にテストする

1. フォームを公開し、外部から回答できる状態にします。
2. Googleへログインしていないブラウザでも開けるか確認します。
3. テスト回答を1件送信します。
4. メール通知と回答記録を確認します。
5. LP・FAQ・利用条件と、フォーム内の商品名・料金が一致しているか確認します。
6. テスト回答を削除します。

## 5．サイトへの反映

現在の `contact/index.html` は、Googleフォームをiframeで直接埋め込んでいます。

フォーム自体を差し替える場合は、次の2か所を更新します。

- `iframe.contact-form-iframe` の `src`
- `a.contact-form-fallback` の `href`

`assets/site.js` の `GOOGLE_FORM_URL` は、将来 `data-google-form` 属性のリンクを使う場合の補助設定です。現行の問い合わせページではiframeのURLが実際の表示先です。
