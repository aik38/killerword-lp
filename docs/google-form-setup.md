# Googleフォーム設定手順

問い合わせフォームは、Googleフォームを別画面で開く方式を使用します。フォームが未設定の間、サイトはメール問い合わせだけを表示します。

## 1．フォームを作成する

1. `https://forms.google.com/` を開きます。
2. 「空白のフォーム」を選びます。
3. フォーム名を `クチコミスターズ｜Googleクチコミの無料相談・お問い合わせ` にします。
4. 説明文へ次を入力します。

> Googleクチコミを増やしたい、低評価への対応を整えたい、Googleマップからの集客を改善したい。現在のお悩みとご希望をお送りください。送信前にプライバシーポリシー（https://killerword.info/privacy/）をご確認ください。

## 2．質問項目を設定する

次の順番を推奨します。

| 項目 | 質問形式 | 必須 |
|---|---|---:|
| 会社名・店舗名 | 記述式 | はい |
| ご担当者名 | 記述式 | はい |
| メールアドレス | 記述式（メール形式の回答検証） | はい |
| GoogleマップURL | 記述式 | はい |
| WebサイトURL | 記述式 | いいえ |
| 店舗数 | 記述式 | いいえ |
| ご希望の内容 | ラジオボタン | はい |
| 現在お困りのこと | チェックボックス | はい |
| ご相談内容・補足 | 段落 | いいえ |
| プライバシーポリシーへの同意 | チェックボックス | はい |

「ご希望の内容」の選択肢：

- 無料相談
- クチコミ運用プラン
- MEO集客プラン
- 30日お試しプラン（10件目標・55,000円）
- 30日お試しプラン（20件目標・88,000円）
- 30日お試しプラン（30件目標・110,000円）
- 複数店舗の相談
- その他

「現在お困りのこと」の選択肢：

- 新しいクチコミが増えない
- クチコミへの返信が止まっている
- 低評価への対応に困っている
- 店舗情報や写真を更新できていない
- 競合店舗よりGoogleマップ上の印象が弱い
- 何から改善すべきか分からない
- その他

同意項目は `プライバシーポリシーを確認し、個人情報の取扱いに同意する` とし、必須にします。

## 3．フォーム設定を確認する

Googleアカウントへのログインを必須にしない設定にします。

- 組織内のユーザーに限定：オフ
- 回答を1回に制限：オフ
- 回答の編集を許可：オフ
- 質問の順序をシャッフル：オフ
- テストにする：オフ
- メールアドレス収集：フォーム内の必須項目で入力してもらう

送信後の確認メッセージは、次を推奨します。

> お問い合わせありがとうございます。内容を確認後、担当者からメールでご連絡します。

「回答」タブのメニューから「新しい回答についてのメール通知を受け取る」をオンにします。必要であれば、回答先をGoogleスプレッドシートへ接続します。

## 4．公開前にテストする

1. フォームを公開し、「リンクを知っている全員」が回答できる状態にします。
2. 回答用リンクを取得し、短縮URLを選びます。
3. Googleへログインしていないブラウザでも開けるか確認します。
4. テスト回答を1件送信します。
5. メール通知とスプレッドシートへの記録を確認します。
6. テスト回答を削除します。

## 5．サイトへ反映する

取得した `https://forms.gle/...` のURLを、`assets/site.js` の次の箇所へ設定します。

```js
const GOOGLE_FORM_URL = "https://forms.gle/ここを差し替え";
```

設定すると、問い合わせページに「Googleフォームから送信する」ボタンが自動表示されます。フォームURLを空に戻すと、ボタンは非表示になります。
