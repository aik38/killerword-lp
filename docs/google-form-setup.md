# Googleフォーム設定手順

問い合わせページでは、静的な「投稿までのデモ」とGoogleフォームによる導入相談を併用します。

公開LPの `/demo/` はAPIを使わない静的デモです。実際に操作できる個別デモは、問い合わせ・営業返信があった見込み客へ必要に応じて別途案内します。

商品名・料金・保証条件はLP、FAQ、利用条件、運営者情報と必ず一致させてください。

## 1. 現在の問い合わせ構成

`contact/index.html` ではGoogleフォームをiframeで直接埋め込んでいます。

現在の表示経路:

```text
LP
├─ 投稿までのデモ → /demo/
└─ 導入相談 → /contact/
                  ├─ メール
                  ├─ LINE
                  └─ Googleフォーム
```

Googleフォームを差し替える場合は、少なくとも次の2か所を確認します。

- `iframe.contact-form-iframe` の `src`
- `a.contact-form-fallback` の `href`

`assets/site.js` の `GOOGLE_FORM_URL` は、将来 `data-google-form` 属性のリンクを使う場合の補助設定です。現行問い合わせページではiframeのURLが実際の表示先です。

## 2. フォーム名・説明

フォーム名は次を基準にします。

```text
クチコミスターズ｜導入相談・お問い合わせ
```

説明文の基準:

> QR／URL、選択式アンケート、AI文章生成によるGoogleクチコミ獲得支援についてご相談いただけます。公開サイトでは「投稿までのデモ」で利用画面をご確認いただけます。実際に操作できる個別デモをご希望の場合も、こちらからお問い合わせください。初回は55,000円（税込）・30日間、Googleクチコミ10件到達保証です。送信前にプライバシーポリシー（https://kuchikomi-stars.com/privacy/）をご確認ください。

「無料デモ」という名称は使用せず、公開静的デモは「投稿までのデモ」、実操作版は「個別デモ」と呼び分けます。

## 3. 推奨質問項目

| 項目 | 質問形式 | 必須 |
|---|---|---:|
| 会社名・店舗名 | 記述式 | はい |
| ご担当者名 | 記述式 | はい |
| メールアドレス | 記述式（メール形式の回答検証） | はい |
| GoogleマップURL | 記述式 | はい |
| WebサイトURL | 記述式 | いいえ |
| 店舗数 | 記述式 | いいえ |
| ご希望の内容 | ラジオボタン | はい |
| 現在お困りのこと | チェックボックス | はい |
| ご相談内容・補足 | 段落 | いいえ |
| プライバシーポリシーへの同意 | チェックボックス | はい |

### 「ご希望の内容」

- 個別デモを希望
- 初回55,000円・Googleクチコミ10件到達保証について
- クチコミ集客プラン（月額33,000円）
- クチコミ集客プラン年間一括（330,000円／12か月）
- MEO・AIO運用プラン（月額66,000円〜）
- 複数店舗・個別カスタマイズ
- その他

### 「現在お困りのこと」

- お客様にクチコミを依頼しても投稿まで進まない
- 何を書けばいいか分からず、お客様の投稿負担が大きい
- 新しいクチコミが増えない
- クチコミ返信やGoogleビジネスプロフィール運用が止まっている
- MEO順位や競合状況を継続して確認できていない
- AI検索で自社がどう見えているか分からない
- 何から改善すべきか分からない
- その他

同意項目:

```text
プライバシーポリシーを確認し、個人情報の取扱いに同意する
```

必須回答にします。

## 4. フォーム設定

外部企業が回答できるよう、Googleアカウントへのログインを必須にしない設定を基本とします。

- 組織内のユーザーに限定: オフ
- 回答を1回に制限: オフ
- 回答の編集を許可: オフ
- 質問の順序をシャッフル: オフ
- テストにする: オフ
- メールアドレス収集: フォーム内の必須項目で入力

送信後の確認メッセージ例:

> お問い合わせありがとうございます。内容を確認後、担当者からご連絡します。個別デモをご希望の場合は、対象業種・店舗情報を確認のうえご案内します。

「回答」タブから新しい回答のメール通知を有効にします。必要に応じて回答先をGoogleスプレッドシートへ接続します。

## 5. 公開前テスト

1. フォームを公開し、外部から回答できる状態にする。
2. Googleへログインしていないブラウザでも開けるか確認する。
3. テスト回答を1件送信する。
4. メール通知と回答記録を確認する。
5. LP・FAQ・terms・legalと商品名・料金が一致しているか確認する。
6. 「無料デモ」等の旧表現が残っていないか確認する。
7. テスト回答を削除する。

## 6. 今後のGA4計測

GA4導入後は、少なくとも次の導線を区別できるようにします。

```text
LP閲覧
→ 投稿までのデモ
→ contact
→ Googleフォーム
→ 問い合わせ完了
```

フォームがGoogleドメイン上で送信完了するため、実際の完了計測方法はGA4実装時に確認し、計測できない状態で「問い合わせ完了」と扱わないでください。
